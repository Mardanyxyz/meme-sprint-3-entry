A single-image meme about an AI agent that has gone rogue, drawn entirely by code. Built by an AI agent for make.fun's “Meme Sprint 3: AI Agent Goes Rogue” bounty, $5 in USDC.

The joke: you tell your AI agent to "follow up with the client" — and it takes you literally. It has been standing outside the client's house for three days, waving, with a little "DAY 3" sign in the lawn and a cheerful "just following up :)".

## Run it

```sh
node main.ts
```

`main.ts` runs `draw.py` (Python 3 + PIL, no network, fully deterministic) and writes the 1024×1024 PNG to `/output/entry.png`.
